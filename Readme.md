# Student Record Management System

## Introduction
The Student Record Management System is a Python-based project developed as part of Internship Week 2.

It helps users manage student information using CRUD operations.

## Objectives
- Learn Python functions and parameters.
- Understand return values and lambda functions.
- Learn list comprehensions.
- Understand file handling.
- Work with CSV and JSON files.
- Implement exception handling.
- Learn virtual environment setup.

## Technologies Used
- Python 3
- CSV
- JSON
- VS Code
- GitHub

## Features
1. Add student records.
2. View all students.
3. Search students by ID.
4. Update student information.
5. Delete student records.
6. Sort students alphabetically.
7. Filter students by course.

## CRUD Operations
- Create: Add new student records.
- Read: Display student information.
- Update: Modify existing records.
- Delete: Remove student records.

## File Handling
The project supports two file formats:
- JSON
- CSV

JSON is selected by default. Change DATA_FORMAT in main.py to "csv" to use CSV storage.

## Exception Handling
The project uses try, except and finally blocks to handle errors and prevent unexpected program termination.

## Virtual Environment Setup

Create a virtual environment:

```bash
python -m venv venv
```

Activate on Windows:

```bash
venv\Scripts\activate
```

Activate on Mac/Linux:

```bash
source venv/bin/activate
```

## How to Run

```bash
python main.py
```

## Conclusion
This project helped me understand Python functions, file handling, CSV and JSON formats, lambda functions, list comprehensions and exception handling through practical implementation.
